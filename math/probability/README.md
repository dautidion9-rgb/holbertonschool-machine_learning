# Probability

This project covers probability distributions, implemented in Python without
importing any modules.

## Files

| File | Description |
| ---- | ----------- |
| `poisson.py` | `Poisson` class that represents a poisson distribution |

## Requirements

- Python 3 (`#!/usr/bin/env python3`)
- No imported modules
- `pycodestyle` compliant
- All modules, classes, and functions are documented
